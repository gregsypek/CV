Projekty

Invest Guard

Zaawansowana platforma typu "Premium Dashboard" do kompleksowego planowania i zarządzania portfelem inwestycyjnym. Zbudowana w architekturze full-stack z wykorzystaniem Next.js, TypeScript, Tailwind CSS v4, Prisma (PostgreSQL) oraz Recharts. Aplikacja umożliwia inteligentne śledzenie docelowej i aktualnej alokacji kapitału, wspierając zarówno tradycyjne giełdy i obligacje, jak i aktywa alternatywne (np. nieruchomości, sztuka). Moduł analityczny oferuje w pełni interaktywne wykresy z płynnymi symulacjami strategii "w locie" oraz zautomatyzowane wyliczanie odchyleń portfela, a wszystko to w estetycznym, dopracowanym interfejsie wspierającym tryb ciemny (Dark Mode).

https://invest-guard-blue.vercel.app Next.js TypeScript Tailwind v4 Prisma Recharts

Schody Zaliński

Kompleksowa realizacja end-to-end nowoczesnej witryny biznesowej dla producenta schodów drewnianych. Projekt został poprowadzony od całkowitej podstawy wizualnej (zaprojektowanie autorskiego logo, UI/UX) aż po finalne wdrożenie i optymalizację. Aplikacja oparta o system WordPress z wykorzystaniem niestandardowego kodowania w PHP, MySQL oraz SCSS. Zakres prac obejmował nie tylko architekturę kodu i wysokiej jakości wizytówkę produktową, ale także copywriting, pełne zaplecze prawne (regulaminy, polityka prywatności), moduł blogowy oraz optymalizację pod kątem wyszukiwarek (SEO). Projekt świetnie demonstruje zdolność do całościowego zarządzania cyklem życia produktu internetowego.

https://schodyzalinski.pl/ WordPress PHP SCSS MySQL SEO

BakeryStore E-Commerce

W pełni funkcjonalna platforma e-commerce typu Full-Stack, zbudowana z myślą o skalowalności i wydajności. Oparta na Next.js 15 (App Router) oraz React 19, aktywnie wykorzystująca Server Components i Server Actions. Projekt cechuje się rygorystycznym bezpieczeństwem typowania dzięki TypeScript i walidacji schematów Zod, a architekturę danych obsługuje Prisma ORM z bazą PostgreSQL. Aplikacja posiada zaawansowane zarządzanie stanem koszyka, bezpieczną integrację płatności opartą na webhookach (Stripe i PayPal), system mailingowy (Resend) oraz dedykowany panel administratora z wizualizacją danych za pomocą Recharts.

https://bakerystore-zeta.vercel.app/ Next.js 15 React 19 TypeScript Prisma Stripe API

Portfolio

Interaktywna wizytówka deweloperska zbudowana jako Single Page Application w React. Projekt kładzie silny nacisk na warstwę wizualną, wydajność (optymalizacja assetów) oraz płynne mikrointerakcje zrealizowane za pomocą Framer Motion. Architektura komponentowa jest spójnie ostylowana przy użyciu zaawansowanych technik SCSS. Za bezserwerową obsługę zapytań kontaktowych od rekruterów i klientów odpowiada zintegrowany moduł EmailJS.

https://gregsypek-p3.vercel.app/ React Framer Motion SCSS EmailJS
